The unit of work on the kanban board: one piece of content, one card.

```jsx
<PieceCard
  id="MNT-1042" title="Carrossel — 5 mitos sobre proteína vegetal"
  client="Verde Natural" clientSlot={2}
  status="Em produção" tone="inprogress"
  channel={{icon:'image',label:'Carrossel'}} due="12 ago" assignee="Ana Ribeiro" comments={3}
/>
```

The sigla block is the only colour on the card besides the status lozenge. Shadow appears only while dragging.
