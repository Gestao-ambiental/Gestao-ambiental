Multi-select and row selection. Works uncontrolled out of the box.

```jsx
<Checkbox label="Instagram" defaultChecked />
<Checkbox isIndeterminate aria-label="Selecionar todas as peças" />
<Checkbox label="Arquivadas" isDisabled />
```

2px radius (the one exception to the 3px rule — it reads squarer at 16px). In table headers use `isIndeterminate` for a partial selection.
