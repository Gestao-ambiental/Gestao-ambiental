Explains a condition of the screen you are on — overdue approvals, a client with no plan for the month.

```jsx
<SectionMessage tone="warning" title="3 peças passaram do prazo de aprovação">
  O cliente foi notificado em 8 ago. Reenvie o link ou remarque a data.
</SectionMessage>
```

Washed tint from the lozenge palette, no border, 3px radius. It belongs in the content column — for transient confirmations use `Toast`.
