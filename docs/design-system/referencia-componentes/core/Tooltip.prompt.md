Names an icon-only control or truncated text. Never carries information you can't get elsewhere.

```jsx
<Tooltip content="Duplicar peça"><IconButton icon="copy" label="Duplicar peça" /></Tooltip>
<Tooltip content="Entrega 12 ago" position="right"><span>12/08</span></Tooltip>
```

`--surface-inverse` surface (#0A241C no claro), 12px text, one line. Appears on hover and focus, disappears instantly.
