Neutral 20px chip for labels, channels and applied filters. Not a status — status is `Lozenge`.

```jsx
<Tag>instagram</Tag>
<Tag color="var(--client-2)">Verde Natural</Tag>
<Tag onRemove={() => remove(id)}>Responsável: Ana</Tag>
```

Always grey; the optional `color` dot is the only colour allowed, and only for client identity.
