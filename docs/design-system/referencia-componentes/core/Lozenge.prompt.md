The only place status is expressed in AgroFuturo — never colour a whole row or card by status.

```jsx
<Lozenge>Briefing</Lozenge>
<Lozenge tone="inprogress">Em produção</Lozenge>
<Lozenge tone="review">Em revisão</Lozenge>
<Lozenge tone="warning">Aguardando aprovação</Lozenge>
<Lozenge tone="success">Publicado</Lozenge>
<Lozenge tone="danger">Atrasado</Lozenge>
```

Text is 11px/700 uppercase with 0.04em tracking, so keep labels to one or two words. Background is always the washed tint, never the bold fill.
